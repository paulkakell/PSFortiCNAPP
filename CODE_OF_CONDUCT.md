# Project Conduct

PSFortiCNAPP is a technical publishing and software project. Participation requires professional, evidence-based communication.

## Expected conduct

Contributors should:

- Address the work rather than the person.
- Distinguish verified facts, observations, inferences, and recommendations.
- Accept correction when evidence changes.
- Protect tenant information, credentials, personal data, and unpublished security details.
- Make room for beginners without weakening technical standards.
- Give clear credit for contributed work and third-party material.

## Unacceptable conduct

The project does not accept harassment, discrimination, threats, deliberate disclosure of protected information, fabricated evidence, impersonation, or repeated disruption of technical review.

## Enforcement

Report conduct concerns privately through the repository maintainer's GitHub profile. Do not include confidential tenant or vulnerability details in a public issue. The maintainer may edit, hide, lock, or remove content and may restrict participation when necessary to protect contributors or the project.

Project decisions should document the technical reason, relevant evidence, and any remaining uncertainty.
