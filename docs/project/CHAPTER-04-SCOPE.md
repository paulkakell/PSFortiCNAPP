# Chapter 4 Scope

Chapter 4 teaches HTTP, JSON, URI, response media type, safe diagnostic metadata, deterministic hashing, and local contract classification.

It does not implement authentication, token lifecycle, live requests, FortiCNAPP endpoints, LQL, retries, pagination, schema discovery, or remediation.

All runnable values are synthetic. Tenant-dependent behavior remains `VERIFY IN TENANT`.
