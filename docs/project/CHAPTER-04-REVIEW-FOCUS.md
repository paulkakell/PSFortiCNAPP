# Chapter 4 Review Focus

Reviewers should examine:

- Beginner clarity of HTTP and JSON explanations
- Separation of transport success from evidence validity
- Query and header redaction
- UTC timestamp requirements
- Deterministic body size and SHA-256
- Structured errors for invalid captured exchanges
- Returned contract state for malformed or unsupported bodies
- Synchronization of manifest, loader, tests, documentation, and formatting
- Preservation of the no-network and no-tenant boundary
