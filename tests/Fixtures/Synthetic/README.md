# Synthetic Fixtures

Every file in this directory is intentionally fabricated for tests, examples, and book labs. No fixture may be produced by merely renaming a real tenant export.

A fixture must include:

- A data-classification field set to `Synthetic`.
- A schema version.
- A stated instructional or test purpose.
- Invented organization, scope, identity, and resource values.
- No credential, personal, customer, or production evidence.

Sanitized fixtures, when later approved, belong in a separate `Sanitized` directory with a documented sanitization method and review record.
