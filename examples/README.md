# Examples

Examples are executable Apache-2.0 material. They use synthetic or explicitly sanitized data and must not require a contributor's profile or stored credential.

The initial foundation examples are:

- `foundations/Test-Environment.ps1`: imports the source module and produces a non-sensitive readiness object.
- `foundations/Review-SyntheticScopeRegister.ps1`: calculates a transparent coverage result from the Chapter 1 synthetic scope register.

Provider-facing examples will be added only after their verification-ledger requirements are satisfied.
